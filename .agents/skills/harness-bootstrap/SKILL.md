# Harness Bootstrap
1. Read AGENTS.md, ANTIGRAVITY.md, PROJECT.md, ARCHITECTURE.md, DECISIONS.md.
2. Read .harness/policy.yaml, contract.yaml, verification.yaml, source_of_truth.yaml, profile.yaml and relevant invariants (including ux_contract.yaml).
3. Inspect the project structure and identify facts, assumptions, unknowns and risks.
4. Do not implement product changes.
5. Report Harness readiness and propose the first Task Contract.
