# Harness Implement
1. Follow the approved Task Contract.
2. Fix the canonical path before adding wrappers, fallbacks or parallel state.
3. Do not invent parameters, fields, endpoints, settings or schemas.
4. Follow design tokens and monochrome icon rules when writing UI code.
5. Keep the change within the task scope.
6. Run deterministic checks before claiming completion.
7. Do not claim success without evidence.
