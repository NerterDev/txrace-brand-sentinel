# Harness Repair
1. Read the failure evidence.
2. Classify the failure (CODE, TEST, CONTRACT, UX_CONTRACT, etc.).
3. Trace the canonical data/control path.
4. Identify root cause before mutation.
5. Apply the smallest correct repair.
6. Re-run verification.
